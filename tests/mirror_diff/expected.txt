# Known differences of tests/mirror_diff on this branch with its submodules (moonlink c1a99ef,
# pg_duckdb 7daa8e5), measured on PostgreSQL 17. The bug classes and the gate are those of
# scripts/e2e-known-bugs.txt (TESTING.md, "Release policy"); the rule syntax is in README.md:
#
#   bug <name> class=blocking|class=limitation <description>
#   check <check-glob> <bug>[,<bug>...] [<regex>]
#   engine <bug>
#
# Rules are pinned to what identifies each bug: the column type and verdict of data checks, the
# event kind and column type of cdc events, the moonlink panic site (file:line:col, per moonlink
# revision), the assertion of a backend crash, or the statement text. A cdc check is XFAIL only if
# every one of its events matches a rule.

engine duckdb-semantics

# ---- documented limitations --------------------------------------------------------------------
bug duckdb-semantics class=limitation Queries on mirrors run in DuckDB and follow its semantics: integer division, overflow errors, char(n) padding, regex ~ full match, errors raised by only one engine
bug json-text-normalised class=limitation json and jsonb values read back from a mirror in DuckDB's compact text form with keys reordered
bug unsupported-types class=limitation mooncake.create_table rejects tables with columns of types mirrors don't support: geometric types, interval, inet/cidr, macaddr/macaddr8, money, bit/varbit, timetz, pg_lsn, xml, tsvector/tsquery, ranges, domains, enums, numeric with precision above 38
bug unsupported-table-shapes class=limitation create_table rejects unlogged tables
bug window-row-order class=limitation Window queries whose result depends on physical row order (ROWS/GROUPS frames or order-sensitive functions over ties) can differ, because a mirror stores rows in a different order than its heap

# ---- types ---------------------------------------------------------------------------------------
bug char-padding-lost class=blocking char(n) values lose their trailing blank padding
bug numeric-digits-shifted class=blocking Unconstrained numeric values come back with their digits shifted
bug numeric-nan-inf-null class=blocking numeric NaN, Infinity and -Infinity read back as NULL
bug numeric-typmod-panic class=blocking numeric with scale greater than precision or a negative scale panics moonlink in create_table
bug numeric-beyond-i128-panic class=blocking A numeric value whose unscaled integer exceeds 128 bits panics the replication task
bug decimal-stats-overflow-panic class=blocking Persisting a numeric column with values beyond 96 bits panics in the Iceberg statistics code
bug date-out-of-range class=blocking date/timestamp values +-infinity, BC or after year 9999 panic the initial copy and silently drop the transaction in CDC
bug arrays-come-back-empty class=blocking Array columns read back as empty arrays ({NULL} becomes {})
bug multidim-arrays class=blocking Multi-dimensional or non-default-bound arrays panic the initial copy, are mangled, or drop the transaction in CDC
bug keyless-nested-copy-panic class=blocking Initial copy of a table without a primary key that has an array or composite column panics the table handler
bug composite-as-struct class=blocking Composite-type values read back as DuckDB STRUCT text instead of the Postgres row value
bug range-array-panic class=blocking A range-array column (int8range[]) panics moonlink in create_table

# ---- CDC and table shapes ----------------------------------------------------------------------
bug unchanged-toast-overwritten class=blocking An UPDATE that doesn't touch an out-of-line (TOASTed) column replaces that column with an empty value in the mirror
bug truncate-ignored class=blocking TRUNCATE of a mirrored source is not applied to the mirror
bug generated-column-breaks-mirror class=blocking Stored generated columns are part of the mirror definition but not replicated, so SELECT * on the mirror fails
bug inheritance-children-ignored class=blocking Mirrors of inheritance parents miss later changes of child tables
bug inheritance-recovery-crash-loop class=blocking With an inheritance parent and child both mirrored, moonlink crash-loops after a restart (child already in the publication)
bug partition-ddl-ignored class=blocking DROP, DETACH or ATTACH PARTITION on a mirrored partitioned table is not reflected in the mirror
bug partition-update-panics class=blocking UPDATE whose old row is missing (multi-level partitions, replica identity not FULL) panics the replication task
bug relation-schema-assert class=blocking A Relation message for a table the CDC stream doesn't know panics the replication task (multi-level partitions)
bug rejected-create-leaves-state class=blocking After create_table is rejected, mirroring a re-created source under the same mirror name fails with "error creating table"
bug drop-after-dead-task-panic class=blocking DROP of a mirror whose table task already died panics moonlink (table_event_manager.rs) and half-drops it
bug snapshot-hangs-after-xidless-wal class=blocking create_snapshot waits forever when the session's last transaction wrote WAL without an xid

# ---- backend crashes (Postgres crash recovery) -----------------------------------------------------
bug duckdb-timezone-commit-abort class=blocking After a DuckDB query in the session, SET LOCAL TIME ZONE + COMMIT aborts the backend (catalog access in the GUC hook at end of transaction)
bug duckdb-multiassign-abort class=blocking UPDATE ... SET (a, b) = (SELECT ...) on a mirror aborts the backend in pg_duckdb's deparser
