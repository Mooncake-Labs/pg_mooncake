# Known failures of scripts/e2e-smoke.sh on this branch with its submodules (moonlink c1a99ef).
#
#   bug <name> blocking|limitation <description>
#   check <scenario.check> <bug> <regex>
#
# blocking: the bug can crash-loop moonlink, panic, lose or silently change mirrored data, or make
# mirrors unusable; it must be fixed before a release, and while one is listed the gate cannot pass.
# limitation: a documented, loud or harmless restriction that ships in the release notes.
#
# A listed check reports XFAIL(<bug>) only when each of its failure signatures matches the regex
# (bash ERE) of one of its listed bugs; any other failure is a plain FAIL. A check may list several
# bugs, one line each. Signatures are the RESULT detail, or for no_moonlink_panics one "<file>:<line>"
# per panic location and for bgworker_no_abnormal_exits / no_postgres_crash_restarts one line per
# kind of exit. A "requires <check> <bug> <earlier check> <bug2>" line makes the check's <bug> rule
# count only if the earlier check failed with <bug2>, for failures whose text alone doesn't name
# the cause (a hung DROP, a missing fence mirror). Panic sites are pinned to file:line per moonlink
# revision.
